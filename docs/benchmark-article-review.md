# Benchmark article review

13 October 2026. The article addresses engineering leads and expert evaluation teams. It explains a proposed validation protocol, backed by an executed public grader experiment. It makes no claim about proprietary micro1 procedures or measured model performance.

## Evidence

- Five hand-written candidates, eight controlled completion cases and 40 recorded verdicts in `examples/benchmark-validity/results.json`. Four ordinary checks accept every candidate; four diagnostic checks distinguish the intentional defects. The script asserts the expected sensitivity matrix and propagates unexpected harness errors.
- All technical references are primary papers, official evaluation documentation or micro1's public workflow description, linked beside the supported claim. The proposed protocol and interpretation are the author's applied analysis.
- Existing lint, type checking, all 10 tests and the production build passed. The final article-index copy received a production build as well.
- New article checked at 320, 390 and 1440 pixels in light and dark modes: no document overflow or prose escaping its container. The three code blocks scroll within their containers.
- Every one of the 11 table-of-contents links was clicked and resolved to an existing heading. The article index leads to the new page and the return link leads back to the index.
- Measured description contrast: 5.94:1 in light mode and 8.90:1 in dark mode. Code text and line numbers use the retained slate colors on `#0b1020`, at approximately 17.28:1 and 7.38:1 respectively.
- Retained navbar, footer, mobile menu, contact states and existing article routes have the prior 125-control and 46-layout-combination review in `senior-positioning-review.md`; their handlers and styling are unchanged.
- Source-link navigation and public deployment are verified after the source and article are pushed together. The canonical URL is the website article; Medium uses the same original source.

## Design direction

Retain the existing portfolio's Bricolage Grotesque headings, DM Sans text, blue/slate palette and editorial article layout. ENERGY 2 / RHYTHM 2 / MOTION 2. The long article needs clear section navigation, readable paragraphs and horizontally scrollable source examples. Remove the decorative window dots and heavy shadow from the shared code block: a code listing needs a language label and readable lines, without imitating an application window.
